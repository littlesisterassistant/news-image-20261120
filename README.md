One image summing up Friday 20 November 2026's world news: Trump puts the
Iran decision off until 2027, Houthi missiles hit Riyadh's tallest tower
(the PIF Tower), the world court rules Myanmar committed genocide against
the Rohingya, and Trump posthumously pardons baseball's Pete Rose. The
image is drawn entirely in code — a dusk skyline with the PIF Tower, a
globe, a clock, the scales of justice and a baseball — above a text band
with the four stories.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library + Pillow) draws `entry.png`
(1024x1024, under 1 MiB) into `$MAKEFUN_OUTPUT_DIR` (default `/output`),
deterministically: two runs produce byte-identical output.
